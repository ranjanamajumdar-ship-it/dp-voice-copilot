Screen 13 · Issues List — Soft UI on a Carbon grid

Surfaces follow the reference style: floating white cards on a tinted canvas, 12px radii, soft elevation, tonal chips. Structure stays Carbon: 8px / 2x spacing grid, IBM Plex Sans, 16px gutters. Filters now live in a bottom sheet on mobile and a right-side drawer on desktop — one component, two containers.

The fold: because operators don’t scroll, the viewport edge is tuned so it always cuts through a card — never flush with one, never in the gap between two — and content visibly passes under a shadowed edge. Both cues appear only when there is genuinely more below; a list that fits shows neither.

Pick-up: issues are auto-assigned first; whatever could not be routed waits in a pool strip pinned to the bottom edge. Unclaimed issues never appear in the sections — the sections mean assigned work, the pool means needs routing. Operators claim with Start working; supervisors can assign or acknowledge.
